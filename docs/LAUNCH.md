# 첫등원 오픈 절차 (LAUNCH)

> 작성 2026-10-21. 각 단계의 **완료 조건**을 모두 확인한 뒤 다음 단계로 넘어간다.
> 담당: 🧑‍💼 = 사업자(대표님), 🤖 = 개발(Claude Code), 👥 = 함께.
> 1·2·3단계는 서로 기다리지 않고 **동시에 진행**한다. 가장 오래 걸리는 것은 카카오 발신번호·템플릿 검수와 약관 문안이다.

```
0 즉시 보안 조치 (오늘)
1 사업·법적 준비 ─┐
2 인프라·계정    ─┼─▶ 4 개발 마무리 ─▶ 5 운영 환경 검수 ─▶ 6 파일럿 ─▶ 7 공개 오픈 ─▶ 8 유료 전환 준비
3 카카오 알림톡  ─┘
```

예상: 1~3단계 병행 2~3주 → 4·5단계 1주 → 파일럿 2~4주 → 공개 오픈.

- [ ] 🧑‍💼 Vercel 프로젝트 환경변수 중 대화·문서에 붙여넣은 적이 있는 값(DB 주소, OAuth 비밀키 등)이 있으면 새로 발급해 교체
- [ ] 🧑‍💼 GitHub 저장소가 **비공개**인지 확인

**완료 조건**: 노출된 토큰이 목록에 없다.

- [ ] 사업자등록 (업종 예: 응용 소프트웨어 개발 및 공급업)
- [ ] 통신판매업 신고 — 유료 전환 전 필수. 베타(무료) 기간에 필요한지 확인 `TODO(확인 필요)`
- [ ] **이용약관** (첫등원 ↔ 학원): 서비스 범위, 베타 조건(3개월 무료·자동 결제 없음), 해지·데이터 내보내기, 종료 후 30일 보관 뒤 비공개, 책임 범위
- [ ] **개인정보처리방침 — 첫등원 명의**: 원장 계정(구글 이메일), 무료 진단·제작 대행 신청(연락처), 보유 기간, 파기, 위탁·국외 이전
- [ ] **학원 홈페이지의 개인정보 처리 구조 결정**
  - 학부모·학생 정보(상담 신청, 레벨테스트 답안·풀이 사진)의 처리자는 **학원**, 첫등원은 **수탁자** — 약관에 위·수탁 조항 포함
  - 학원별 개인정보처리방침에 들어갈 기본 문안 확정 (개발에서 학원 정보로 자동 생성 — 4단계)
- [ ] **국외 이전 고지**: Vercel(미국), Neon(DB 리전 확인), Anthropic(미국, AI 초안 사용 시), Aligo(국내)
- [ ] 미성년자: 상담 신청을 학부모가 하고 레벨테스트는 상담 건에 연결되므로 학부모 동의로 충분한지 확인 (만 14세 미만 법정대리인 동의) `TODO(확인 필요)`
- [ ] 문서에 남아 있는 확인 항목 결정 (SPEC의 `TODO(확인 필요)`)
  - 환불 기준 기본 문구(학원법 시행령 대조), 학원 광고 표시 의무 항목, 과장광고 금지어
  - 광고성 메시지 수신 동의 2년 재확인 문구, 개인정보 보존 기간(상담 기록 `retainUntil`)

**완료 조건**: 이용약관·첫등원 개인정보처리방침·학원용 처리방침 기본 문안이 확정 문서로 있다.

## 2단계 — 인프라·계정

- [ ] 🧑‍💼 **Vercel Pro 전환** — Hobby는 비상업용이라 유료 서비스에 쓸 수 없다. Pro면 크론을 5분 간격으로 돌릴 수 있어 "3시간 미응대 재알림"도 다시 가능
- [ ] 🧑‍💼 **Neon**: 운영 플랜(자동 백업·시점 복구 지원 여부), DB 리전 확인, 백업에서 복구해 보기 1회
- [ ] 🧑‍💼 **Vercel Blob** 저장소를 프로젝트에 연결 (학생 풀이 사진·원장 사진·자료 첨부)
- [ ] 🧑‍💼 **Google OAuth**
  - 동의 화면 게시 상태를 **"프로덕션"**으로 (테스트 상태면 등록한 테스트 사용자만 로그인 가능)
  - 승인된 리디렉션 URI: `https://growweb.me/api/auth/callback/google`
  - 앱 이름·로고·개인정보처리방침 URL(`https://growweb.me/privacy` — 4단계 후)
- [ ] 🧑‍💼 **도메인** growweb.me: Vercel 연결·HTTPS, `www` → 루트 리디렉션, 문의 받을 이메일 주소
- [ ] 👥 **환경변수** (Vercel → Settings → Environment Variables, Production)

| 이름 | 필수 | 내용 |
|---|---|---|
| `DATABASE_URL` | ● | Neon 연결 주소 |
| `DIRECT_URL` | ○ | Neon 직접 연결 주소(마이그레이션용, 풀러를 쓸 때) |
| `AUTH_SECRET` | ● | 32바이트 이상 무작위 값 (`openssl rand -base64 32`) |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | ● | Google OAuth |
| `PLATFORM_ADMIN_EMAILS` | ● | 운영자 구글 이메일(쉼표 구분) |
| `NEXT_PUBLIC_BASE_URL` | ● | `https://growweb.me` |
| `MESSAGING_SECRET` | ● | 연락처 해시용 무작위 값. **한 번 정하면 바꾸지 않는다**(바꾸면 기존 발송 기록과 대조 불가) |
| `CRON_SECRET` | ● | 예약 작업 보호용 무작위 값 |
| `BLOB_READ_WRITE_TOKEN` | ● | Blob 연결 시 자동 |
| `KAKAO_API_KEY`, `KAKAO_USER_ID`, `KAKAO_SENDER_KEY`, `KAKAO_SENDER_TEL` | ● | 3단계에서 발급. 없으면 카톡은 실제로 나가지 않음(모의 발송) |
| `SMS_FALLBACK_TEL` | ○ | 문자 대체 발송 번호(없으면 `KAKAO_SENDER_TEL`) |
| `VERCEL_TOKEN`, `VERCEL_PROJECT_ID`, `VERCEL_TEAM_ID` | ○ | 학원 커스텀 도메인 셀프 연결. **0단계 이후 새로 발급한 토큰**, 프로젝트 권한만 |
| `ANTHROPIC_API_KEY` | ○ | AI 초안(원장 소개·수업·소식). 없으면 기능 숨김 |
| `RESEND_API_KEY` | ○ | 운영자 알림 메일(무료 진단·제작 대행 신청·셀프 개설). resend.com에서 발급. 없으면 메일 안 나감 |
| `OPERATOR_NOTIFY_EMAIL` | ○ | 넣지 않으면 `lib/mail/operator.ts`의 `OPERATOR_EMAIL`로 보낸다. 다른 주소로 바꿀 때만(쉼표 구분). 도메인 인증 전에는 Resend 가입 메일만 가능 |
| `MAIL_FROM` | ○ | 보내는 주소. growweb.me 도메인 인증 후 `첫등원 <noreply@growweb.me>` 등. 없으면 `onboarding@resend.dev` |

**완료 조건**: Pro 플랜, 필수 환경변수 모두 입력, 운영자 계정으로 `https://growweb.me/platform` 로그인 성공.

## 4단계 — 개발 마무리 🤖

오픈을 막는 것(●)부터 처리한다.

- [ ] ● **`/privacy`, `/terms` 페이지** — 1단계 문안으로 작성, 푸터·가입 동의 문구에서 링크
- [ ] ● **학원 홈페이지별 개인정보처리방침 페이지** (`/{slug}/privacy`) — 학원명·연락처를 넣어 자동 생성, 상담 신청 폼·푸터에서 링크
- [ ] ● **알림톡 템플릿 코드 연결** — 지금은 시나리오 이름(`receipt` 등)을 템플릿 코드로 보내므로 실제 발송이 실패한다. Aligo 발급 코드와 연결(환경변수), 버튼이 있는 템플릿이면 버튼 값 포함
- [ ] ● 레벨테스트 응시 링크·채점 완료 알림을 알림톡으로 (3단계 템플릿 승인 후)
- [ ] ● **운영 DB 점검** — 빌드 로그의 `migrate-baseline` 결과 확인, 운영 DB와 스키마 비교(읽기 전용 연결 주소를 주시면 확인)
- [ ] ● 개인정보 보존 기간이 지난 상담 기록 익명화 작업 (1단계에서 기간 확정 후)
- [ ] ○ 공개 입력창 남용 방지: 상담 신청·무료 진단·사진 업로드에 요청 횟수 제한 (지금은 상담 폼 허니팟·7일 중복 방지만)
- [ ] ○ 오류 알림: Vercel 로그 알림 또는 오류 추적 서비스 연결, 크론 실패 알림
- [ ] ○ `/platform` 접속 시 로그인 후 원래 화면으로 돌아오기
- [ ] ○ Pro 전환 시 미응대 재알림을 "신청 후 3시간"으로 복원(선택)
- [ ] ○ 테스트로 만든 학원·계정 정리 (데모 학원 3곳은 유지)

**완료 조건**: ● 항목 완료, 자동 테스트 통과, 운영 배포 성공.

## 5단계 — 운영 환경 검수 👥

실제 사이트(`growweb.me`)에서 **실제 휴대폰**으로 테스트용 학원 하나를 만들어 처음부터 끝까지 진행한다.

| # | 해 볼 것 | 기대 결과 |
|---|---|---|
| 1 | 새 구글 계정으로 `/start` 셀프 개설 | 홈페이지 즉시 공개, 대시보드 체크리스트 |
| 2 | 학원 정보·수업·교습비 입력, 테마·섹션 변경 후 되돌리기 | 홈페이지에 즉시 반영, 이력에서 복원 |
| 3 | 설정에 내 휴대폰을 새 상담 알림 번호로 등록 | — |
| 4 | 다른 휴대폰으로 홈페이지에서 상담 신청 | 학부모 폰에 접수 알림톡, 원장 폰에 새 상담 알림톡 |
| 5 | 관리자 상담 관리에서 상태 변경·메모 (휴대폰 화면) | 기록 남음, 연락처는 상세에서만 전체 표시 |
| 6 | 문제은행 → 시험지 → 응시 링크 보내기 | 학부모 폰에서 링크 열림 |
| 7 | 학생 폰으로 응시, 서술형에 풀이 사진 업로드, 제출 | 결과지 "채점 중", 상담 "테스트 완료" |
| 8 | 채점함에서 점수·첨삭·펜 표시 후 채점 완료 | 결과지에 최종 점수·첨삭 |
| 9 | 다음 날 오전 9시 전후 | 미응대 상담 아침 알림 수신 |
| 10 | 플랫폼 관리자에서 베타 종료일을 10일 뒤로 | 대시보드 배너, 다음 날 원장에게 안내 알림톡 |
| 11 | 데이터 내보내기 | 파일 내려받기 |
| 12 | (선택) 커스텀 도메인 연결 | DNS 안내 → 연결 확인 → 그 주소로 열림 |
| 13 | 무료 진단에 실제 학원 블로그 주소 | 즉석 결과지 |
| 14 | 플랫폼 관리자 휴대폰 화면 | 메뉴·학원 목록·대행 접속 정상 |

**완료 조건**: 14개 모두 기대대로 동작. 문제는 4단계로 돌려 고친 뒤 다시 확인.

## 6단계 — 파일럿 (2~4주) 👥

- [ ] 지인·소개 학원 **3~5곳** 모집 (과목·테마가 겹치지 않게)
- [ ] 개설은 원장이 직접(`/start`), 막히는 지점만 옆에서 지원하고 기록
- [ ] 주간 지표: 개설 완료까지 걸린 시간, 체크리스트 완료율, 상담 신청 수, 알림톡 실패율, 레벨테스트 응시·제출률
- [ ] 주 1회 원장 통화 → 개선 목록 → 우선순위대로 수정·배포
- [ ] 오류 로그 매일 확인

**완료 조건**: 파일럿 학원 모두 실제 상담을 1건 이상 받았고, 막는 문제가 없다.
