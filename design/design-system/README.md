# 첫등원 디자인 시스템

동네 학원·교습소의 신규 상담을 등록으로 잇는 서비스, 첫등원의 디자인 기준입니다. 한 벌의 컴포넌트로 네 가지 얼굴을 만듭니다. 원장님을 만나는 **첫등원 서비스 사이트**, 그리고 학부모를 만나는 **학원 템플릿 테마 A·B·C**. 원장님이 쓰는 **관리자 화면**은 테마와 상관없이 하나입니다.

이 문서는 지금까지 만든 시안(첫등원 서비스 홈페이지, 학원 홈페이지·관리자, 테마 3종 비교)에서 실제로 쓴 값을 그대로 옮겼습니다.

## 테마 구조

| 테마 id | 이름 | 누구를 위한 화면 | 첫인상 |
|---|---|---|---|
| `fd` | 첫등원 서비스 | 원장님 (영업·가입) | 남색과 스쿨버스 노랑, 단정한 고딕 |
| `warm` | 테마 A 원장 직강형 | 소규모 학원·교습소 학부모 | 종이색 바탕, 칠판 녹색, 명조 제목 |
| `result` | 테마 B 성과 중심형 | 내신·입시 학원 학부모 | 남색 히어로, 진한 파랑, 굵은 고딕과 큰 숫자 |
| `bright` | 테마 C 밝은 친근형 | 초등·영어·예체능 학부모 | 흰 바탕과 파스텔 카드, 청록, 둥근 제목 |

- 테마는 **색과 제목 글꼴만** 바꿉니다. 컴포넌트의 구조, 간격, 동작은 같습니다. 테마별로 컴포넌트를 복제하지 않습니다.
- 페이지 루트에 `data-theme="warm"`처럼 지정하면 `ink`, `accent`, `subtle` 같은 같은 이름의 토큰이 테마 값으로 바뀝니다. 그래서 컴포넌트는 항상 의미 이름(`accent`)으로만 색을 씁니다. `#1e5645` 같은 값을 직접 쓰지 않습니다.
- 학원 원장님이 바꿀 수 있는 건 `accent` 하나입니다. 바꾼 색이 `on-accent`(흰색)와 4.5:1 대비가 안 나오면 저장을 막습니다.
- 관리자 화면은 `admin-*`, `status-*` 토큰을 씁니다. 테마가 바뀌어도 같습니다.

## 말투와 글

첫등원의 글은 **원장님 옆에서 일 잘하는 실장님**처럼 씁니다. 짧고, 구체적이고, 약속은 지킬 수 있는 만큼만 합니다.

- **존댓말, 짧은 문장.** "상담 신청이 접수되었습니다. 원장이 내일까지 직접 연락드리겠습니다."
- **기능보다 결과로.** "알림톡 자동화" 대신 "바쁜 수업 시간에도 안내는 나갑니다."
- **보장하지 않습니다.** "상담 N% 증가" 같은 약속 대신 "매달 숫자를 그대로 보여드립니다."
- **숫자는 기준과 함께.** 성적·성과 숫자 옆에는 언제나 집계 기준(`caption` 스타일)을 붙입니다. 기준 없는 숫자는 게시하지 않습니다.
- **대괄호는 실제 데이터 자리.** 시안의 `[학원명]`, `[000,000원]`은 관리자 입력값으로 바뀌어야 하며 화면에 대괄호가 남으면 안 됩니다.
- **학부모 화면은 학원의 목소리.** 테마 A는 차분하게, B는 단정하게 숫자로, C는 다정하게("한 번 와서 같이 수업해봐요"). 첫등원이라는 이름은 학부모 화면에 드러내지 않습니다.
- 버튼 문구는 동사로 끝냅니다: "무료 레벨테스트 신청", "베타 신청하기", "전화 걸기". "확인", "제출" 같은 막연한 말은 쓰지 않습니다.

## 색

- **바탕은 `bg`, 카드는 `surface`, 구획은 `subtle`.** 테마 A만 `bg`가 종이색이라 카드가 떠 보입니다.
- **글자는 세 단계.** 제목 `ink`, 본문 `body`, 보조 `muted`. 세 가지 모두 `bg`·`surface`·`subtle` 위에서 4.5:1 이상입니다.
- **`accent`는 행동에만.** 주요 버튼, 선택된 상태, 링크. 장식 면적으로 넓게 깔지 않습니다. 한 화면의 주요 버튼(`accent` 채움)은 하나입니다.
- **`highlight`는 배경 전용.** 첫등원 노랑(`#f5b700`)이나 분필 노랑 위 글자는 항상 `ink`입니다. 노랑을 글자색으로 쓰면 읽히지 않습니다. 테마 B에서는 어두운 히어로 위 강조 숫자에만 씁니다.
- **경고는 `warn-bg` + `warn-ink`.** 마감, 미등록, 정보 불일치에만. 빨강 계열은 상태를 뜻할 때만 작게 씁니다.
- **어두운 구획은 `dark`.** 히어로(테마 B), CTA 띠, 상담 폼 패널, 푸터. 그 위 카드는 `dark-surface`, 글자는 `on-dark` / `on-dark-muted`.
- **파스텔(`pastel-sky`, `pastel-pink`, `highlight-soft`)은 테마 C의 카드 배경.** 다른 테마에서는 `subtle`과 같은 값이라, 테마 C 전용 섹션을 다른 테마에서 켜도 어색하지 않습니다.

### 관리자 상태 배지

상담 상태는 색 차이가 아니라 **밝기 차이**로도 구분되게 했습니다. 등록(`status-enrolled-bg`)만 진한 채움이라 흑백으로 봐도 가장 눈에 띕니다.

| 상태 | 배경 | 글자 |
|---|---|---|
| 신규 | `status-new-bg` | `status-new-ink` |
| 연락 완료 | `status-contacted-bg` | `status-contacted-ink` |
| 테스트 예약 | `status-test-bg` | `status-test-ink` |
| 등록 | `status-enrolled-bg` | 흰색 |
| 미등록 | `status-lost-bg` | `status-lost-ink` |

## 글꼴

모든 글꼴은 Google Fonts에서 불러옵니다. 시스템에 파일로 들어 있지 않으므로 페이지마다 링크를 넣어야 합니다.

- **본문·UI: IBM Plex Sans KR** (`sans`) — 모든 화면의 본문, 버튼, 폼, 관리자 전체.
- **테마 A 제목: Gowun Batang** (`serif`) — 원장의 목소리를 담는 따뜻한 명조. 히어로, 섹션 제목, 후기 인용에만.
- **테마 B 제목: Gothic A1 800** (`grotesk`) — 성적 숫자와 제목. 숫자에는 `font-variant-numeric: tabular-nums`.
- **테마 C 제목: Jua** (`round`) — 둥글고 친근한 제목. 굵기가 하나뿐이라 본문에는 쓰지 않습니다.
- 첫등원 서비스 사이트는 IBM Plex Sans KR 하나로 굵기만 바꿉니다 (`display-xl` 700).
- 본문은 16px 아래로 내리지 않습니다. 입력칸 글자도 16px이어야 휴대폰에서 화면이 확대되지 않습니다. 가장 작은 글자는 `caption` 13px.
- 제목에 음수 자간(-0.8 ~ -1.5px)을 줍니다. 본문에는 주지 않습니다.

## 레이아웃

- **모바일 먼저.** 학부모 유입 대부분이 휴대폰입니다. 390px에서 먼저 확인합니다. 좌우 여백 `space-5`.
- **모바일 하단 고정 바**는 모든 학부모 페이지에 있습니다: 전화 · 카카오톡 · 주요 신청 버튼 (`MobileActionBar`).
- **데스크톱 여백.** 학원 템플릿 좌우 `space-20`, 섹션 사이 `space-30`. 첫등원 사이트는 콘텐츠 최대 폭 `container`(1200px)에 좌우 `space-14`.
- **카드 그리드 간격** `space-4`~`space-6`. 카드 안쪽 `space-8`.
- **모서리는 테마의 성격.** 테마 B는 각지게(`radius-sm`~`radius-md`), 테마 A와 첫등원은 중간(`radius-md`~`radius-lg`), 테마 C는 크게(`radius-xl`~`radius-2xl`, 버튼은 `radius-pill`).
- **그림자는 거의 쓰지 않습니다.** 면 색 차이와 `line`으로 구분하고, 그림자는 히어로 위 떠 있는 카드(`shadow-float`)와 단독 패널(`shadow-panel`)에만.
- 터치 대상은 최소 `tap-min`(44px). 학부모 폼 입력칸 `input-h`, 주요 버튼 `button-lg`.

## 폼과 동의

- 라벨은 입력칸 위, `small` 600. 자리표시자(placeholder)는 예시일 뿐 라벨을 대신하지 않습니다.
- **동의는 분리합니다.** `[필수] 개인정보 수집·이용`, `[선택] 특강·모집 안내 수신`, `[선택] 21시~08시 수신`. 모두 기본 미체크. 야간 수신은 마케팅 동의 아래 들여쓰기 (`ConsentGroup`).
- 제출 버튼 아래에는 다음에 무슨 일이 일어나는지 한 줄로 씁니다. "신청하시면 카카오톡으로 접수 확인 메시지를 바로 보내드립니다."
- 학부모 폼은 짧게. 이름, 연락처, 학년, 상담 유형까지가 기본입니다.

## 아이콘과 이미지

- 아이콘은 **2px 선 아이콘**, 끝 둥글게(`stroke-linecap: round`), 24px 격자. 색은 글자색을 따릅니다. 전화, 말풍선(카카오톡 상담), 메뉴, 뒤로, 체크, 카메라 정도만 씁니다.
- **이모지를 UI에 쓰지 않습니다.**
- 학원 사진은 실제 사진만. 사진이 없을 때는 `subtle` 면에 "[교실 사진]"처럼 무엇이 들어갈지 적어 둡니다. 얼굴이 나온 아이 사진은 보호자 동의를 받은 경우에만 올립니다.
- 카카오, 네이버 로고를 흉내 낸 그래픽을 만들지 않습니다. 버튼 문구로 구분합니다.

## 로고

첫등원 로고는 노랑 원 안에 남색 점이 있는 표식과 "첫등원" 글자입니다 (Logos 그룹). 아침 등원길의 해이자 학원 차 정류장 표시입니다. 표식 노랑은 `#f5b700`, 점과 글자는 `#14213d`. 어두운 바탕(푸터)에서는 점을 바탕색으로 바꾸고 글자를 흰색으로 씁니다. 학부모용 학원 화면에는 첫등원 로고를 넣지 않습니다.

## 컴포넌트

| 컴포넌트 | 쓰는 곳 |
|---|---|
| `Button` | 모든 화면. 주요(accent 채움) · 보조(테두리) · 강조(highlight 채움, 첫등원 사이트·dark 위) |
| `TextField` | 학부모 폼, 관리자 폼 |
| `ConsentGroup` | 모든 신청 폼 |
| `StatusBadge` | 관리자 상담 목록·상세, 대시보드 |
| `ClassCard` | 학원 템플릿 수업 안내, 홈 |
| `MobileActionBar` | 학원 템플릿 모든 페이지(모바일) |

## 하지 않는 것

- 테마별로 다른 구조의 페이지를 만들지 않습니다. 섹션을 켜고 끄고 순서를 바꿀 뿐입니다.
- 그라디언트, 유리 효과, 왼쪽 굵은 테두리 카드, 이모지 카드를 쓰지 않습니다.
- 기준 없는 성과 숫자, 동의 없는 후기, 보장 문구를 쓰지 않습니다.
- 출결·수납처럼 학원관리 프로그램이 하는 기능을 첫등원 기능처럼 보이게 하지 않습니다.
