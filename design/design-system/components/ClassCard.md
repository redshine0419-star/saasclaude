# ClassCard

학원의 반 하나를 보여주는 카드로, 학부모가 "우리 아이에게 맞는 반이 있나"를 확인하는 곳입니다.

- 내용 순서: 반 이름 · 잔여석 배지 → 요일·시간 → 정원·교재 → 한두 문장 소개.
- 잔여석 배지: 여유 `accent-soft`/`accent-ink`, 마감 `warn-bg`/`warn-ink`("마감 · 대기 접수").
- 테마별로 바뀌는 것은 모서리(A `radius-lg`, B `radius-sm`+`line` 테두리, C `radius-2xl`+파스텔 바탕)와 반 이름 글꼴(C만 `round`)뿐입니다.
- 잔여석은 관리자 A-07에서 원장이 바꾸면 바로 반영됩니다. 0이면 자동으로 마감 배지.
- 사용하는 쪽이 정할 것: 반 데이터(이름, 대상, 요일, 시간, 정원, 잔여석, 교재, 소개).
