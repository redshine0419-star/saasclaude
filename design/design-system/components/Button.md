# Button

행동을 하나 고르게 하는 버튼으로, 주요·보조·강조 세 가지가 있습니다.

- **주요**: `accent` 채움 + `on-accent` 글자. 한 화면(모바일은 한 화면 높이)에 하나만. 상담 신청처럼 그 페이지의 목적이 되는 행동.
- **보조**: `surface` 바탕 + `ink` 1px 테두리. "데모 먼저 보기", "요금 보기".
- **강조**: `highlight` 채움 + `ink` 글자. 첫등원 사이트와 `dark` 구획 위에서만 (예: 남색 CTA 띠 위 "무료 진단 신청").
- 높이: 주요 CTA `button-lg`(56px), 일반 52px, 관리자 44px. 최소 `tap-min`.
- 모서리는 테마를 따릅니다: 첫등원·A `radius-md`, B `radius-sm`, C `radius-pill`.
- 문구는 동사로 끝냅니다. "확인", "제출" 금지.
- 사용하는 쪽이 정할 것: 문구, 이동할 곳, 크기(기본/큰), 종류.
