# MobileActionBar

학부모용 모든 페이지의 휴대폰 화면 하단에 고정되는 행동 바입니다.

- 구성: 전화(아이콘) · 카카오톡 상담(아이콘) · 주요 신청 버튼(남은 폭 전부).
- 신청 문구는 테마를 따릅니다: A "무료 레벨테스트 신청", B "레벨테스트 신청", C "무료 체험 수업 신청".
- 아이콘 버튼 52px, 각각 `aria-label` 필수. 테마 C는 카톡 버튼만 `highlight` 채움.
- 아래쪽에 기기 홈 표시줄 높이만큼 여백(약 28px)을 둡니다.
- 상담 신청 화면 자체에서는 이 바 대신 제출 버튼을 고정합니다.
- 데스크톱(넓은 화면)에서는 숨기고 헤더의 버튼을 씁니다.
- 사용하는 쪽이 정할 것: 전화번호, 카카오톡 채널 주소, 신청 페이지 주소.
