# StatusBadge

관리자에서 상담의 현재 상태를 보여주는 작은 배지입니다.

- 다섯 상태: 신규 · 연락 완료 · 테스트 예약 · 등록 · 미등록. `status-*` 토큰 쌍만 씁니다.
- 등록만 진한 채움(`status-enrolled-bg` + 흰 글자). 흑백으로 봐도 구분됩니다.
- 시간 정보를 붙일 수 있습니다: "신규 · 2시간 전", "테스트 후 3일".
- 같은 모양을 수업 안내의 "마감 · 대기 접수", "잔여 2석"에도 씁니다 (잔여석은 `accent-soft` + `accent-ink`).
- `caption` 13px 700, 모서리 `radius-sm`.
- 사용하는 쪽이 정할 것: 상태, 덧붙일 시간 문구.
